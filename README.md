# ADVANZA — Interactive Advertising Network

Keynote pitch presentation deck for ADVANZA: Turning Retail Screens into Playable Brand Experiences.

## Overview
- Interactive 14-slide web-based keynote presentation
- Built with HTML5, CSS3, JavaScript, SVG vector animation, and HTML5 video
- Discrete slide flipping with mousewheel, arrow keys, touch, and HUD controls
- Dedicated interactive modules for problem exploration, side-by-side comparison, physical touchpoint connectivity, and the campaign lifecycle (How It Works)

## Running the Presentation
Open `index.html` in any modern web browser or run `run_keynote.bat`.
